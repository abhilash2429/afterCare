# AfterCare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a deployed AWS web app that turns a photographed Indian discharge summary into a picture-and-voice medicine schedule in the caregiver's language, checks the pill box against the prescription, and escalates missed doses to family.

**Architecture:** Next.js 15 static-export PWA on Amplify Hosting calls a single Python Lambda behind a Function URL. That Lambda runs Textract (words + bounding boxes) then Bedrock Claude Sonnet 5 (structuring with source-block citations), stores plans in a single DynamoDB table, and creates one EventBridge Scheduler one-time schedule per dose slot. A second Lambda fires reminders (Web Push) and escalations (WhatsApp via End User Messaging Social, SES email fallback). All storage is ap-south-1.

**Tech Stack:** Python 3.12 Lambda (local dev on 3.11), AWS CDK v2 (Python), DynamoDB, S3, Textract, Bedrock, Translate, Polly, EventBridge Scheduler, Cognito, SES, End User Messaging Social, Next.js 15 + TypeScript + Tailwind, Amplify Hosting.

**Spec:** [docs/spec.md](../../spec.md) · **API contract:** [docs/api/openapi.yaml](../../api/openapi.yaml)

## Global Constraints

Every task's requirements implicitly include this section.

- **Region:** `ap-south-1` for all resources. Bedrock uses the **global** cross-region inference profile; the profile ID is resolved with `aws bedrock list-inference-profiles` and written into `infra/config.py`. **Never hard-code a Bedrock model ID from memory.**
- **Runtime:** Lambda Python 3.12. Local Python is 3.11.4, so **no 3.12-only syntax** (no PEP 695 `type` statements, no `itertools.batched`).
- **Dependencies:** stdlib + boto3 first. Only three third-party packages are permitted: `PyJWT`, `cryptography`, `pywebpush`. **No pydantic, no rapidfuzz, no requests** — use dataclasses, `difflib`, and `urllib`.
- **Safety rules from spec §7 are enforced in code, not prompts.** A prompt-only guard is a failed task.
- **Logging:** never log document text, medicine names, emails or phone numbers. Only IDs, through `common.redact()`.
- **Money/safety paths** (plan validation, box check verdicts, dose state) each leave a runnable `pytest` test behind.
- **Copy rule:** no screen or API message ever says a medicine is "safe". Box Check language is exactly: "matches your prescription" / "check with your chemist" / "do not take — ask your doctor".
- **Commits:** small and frequent. This repo's history must start after 2026-09-17. Conventional commit prefixes (`feat:`, `fix:`, `test:`, `chore:`).
- **Hard freeze:** Sunday 2026-09-20, 14:00 IST. After that, video and writeup only.

```python
import re

_WORD = {
    "od": ["morning"], "qd": ["morning"], "daily": ["morning"], "once daily": ["morning"],
    "bd": ["morning", "night"], "bid": ["morning", "night"], "twice daily": ["morning", "night"],
    "tds": ["morning", "noon", "night"], "tid": ["morning", "noon", "night"],
    "qid": ["morning", "noon", "night", "bedtime"], "qds": ["morning", "noon", "night", "bedtime"],
    "hs": ["bedtime"], "nocte": ["bedtime"], "at bedtime": ["bedtime"],
}
_PRN = ("sos", "prn", "as needed", "if needed", "when required")
_POSITIONAL_3 = ["morning", "noon", "night"]
_POSITIONAL_4 = ["morning", "noon", "night", "bedtime"]


def parse_frequency(text):
    """Return (slots, is_prn). Unknown input returns ([], False) - never guessed."""
    if not text:
        return [], False
    t = re.sub(r"[.\s]+", " ", str(text).strip().lower()).strip()
    if any(p in t for p in _PRN):
        return [], True
    squashed = t.replace(" ", "")
    if squashed in _WORD:
        return list(_WORD[squashed]), False
    if t in _WORD:
        return list(_WORD[t]), False
    m = re.fullmatch(r"(\d)\s*-\s*(\d)\s*-\s*(\d)(?:\s*-\s*(\d))?", t)
    if m:
        digits = [g for g in m.groups() if g is not None]
        names = _POSITIONAL_4 if len(digits) == 4 else _POSITIONAL_3
        return [names[i] for i, d in enumerate(digits) if d != "0"], False
    return [], False
```

```python
GENERIC_RED_FLAG_TEXT = (
    "Call your doctor or 108 immediately for: chest pain, breathlessness, heavy "
    "bleeding, fever above 101°F, fainting or confusion. This is general advice "
    "— it was not found in your document."
)

_CONFIDENCE_FLOOR = 0.85


def validate_plan(plan):
    """Spec section 7. Returns a list of human-readable errors; empty means valid."""
    errors = []
    rf = plan.redFlags
    if rf is not None:
        if rf.source not in ("document", "generic"):
            errors.append("redFlags.source must be 'document' or 'generic'")
        if rf.source == "document" and not rf.sourceBlockIds:
            errors.append("redFlags.sourceBlockIds must be non-empty when source is 'document'")
        if rf.source == "generic" and rf.text != GENERIC_RED_FLAG_TEXT:
            errors.append("redFlags.text must be the fixed generic constant")

    for m in plan.medicines:
        has_values = bool(m.molecules) or m.frequency is not None or m.durationDays is not None
        if has_values and not m.sourceBlockIds and m.source != "vision_only":
            errors.append("%s: sourceBlockIds required for extracted values" % m.lineId)
        if m.source == "vision_only" and not m.needsConfirmation:
            errors.append("%s: vision_only medicines must set needsConfirmation" % m.lineId)
        if m.prn and m.slots:
            errors.append("%s: prn medicines must not be scheduled (slots must be empty)" % m.lineId)
        if m.frequency is None and m.slots:
            errors.append("%s: slots present but frequency is null - never inferred" % m.lineId)
        if m.confidence < _CONFIDENCE_FLOOR and not m.needsConfirmation:
            errors.append("%s: confidence below floor must set needsConfirmation" % m.lineId)
    return errors


def _dose_signature(plan):
    out = {}
    for m in plan.medicines:
        out[m.lineId] = (
            tuple(sorted((x.name.lower(), x.strengthMg) for x in m.molecules)),
            (m.frequency or "").lower(),
        )
    return out


def validate_edit(original, edited, user_edited):
    """A strength or frequency may only change with an explicit user edit."""
    errors = validate_plan(edited)
    if user_edited:
        return errors
    before, after = _dose_signature(original), _dose_signature(edited)
    for line_id, sig in after.items():
        if line_id in before and before[line_id] != sig:
            errors.append("%s: dose or frequency changed without userEdited=true" % line_id)
    return errors


def can_activate(plan):
    errors = validate_plan(plan)
    pending = [m.lineId for m in plan.medicines if m.needsConfirmation]
    if pending:
        errors.append("confirm these before activating: %s" % ", ".join(pending))
    if not plan.medicines:
        errors.append("plan has no medicines")
    return errors
```

```python
import difflib
import re

from api.models import Molecule

_FORMS = r"\b(tab|tabs|tablet|cap|caps|capsule|syp|syrup|inj|injection|oint|drops|susp)\b"
_MATCH_FLOOR = 0.88


def normalise_brand(text):
    if not text:
        return ""
    t = str(text).lower()
    t = re.sub(r"\(.*?\)", " ", t)
    t = re.sub(r"[.\-/,]", " ", t)
    t = re.sub(_FORMS, " ", t)
    t = re.sub(r"\b\d+(\.\d+)?\s*(mg|mcg|g|ml|iu)?\b", " ", t)
    t = re.sub(r"\bstrip of\b|\bof\b", " ", t)
    return re.sub(r"\s+", " ", t).strip()


def bucket_key(normalised):
    return (normalised or "")[:4]


def parse_composition(text):
    """'Amoxycillin (500mg) + Clavulanic Acid (125mg)' -> two Molecules (strength in mg)."""
    if not text:
        return []
    out = []
    for part in re.split(r"\s*\+\s*", str(text)):
        part = part.strip()
        if not part:
            continue
        m = re.search(r"\(?\s*(\d+(?:\.\d+)?)\s*(mg|mcg|g|ml|iu)\s*\)?", part, re.I)
        strength = None
        if m:
            value, unit = float(m.group(1)), m.group(2).lower()
            strength = {"mcg": value / 1000.0, "g": value * 1000.0}.get(unit, value)
        name = re.sub(r"\(.*?\)", " ", part)
        name = re.sub(r"\d+(\.\d+)?\s*(mg|mcg|g|ml|iu)", " ", name, flags=re.I)
        name = re.sub(r"\s+", " ", name).strip().lower()
        if name:
            out.append(Molecule(name=name, strengthMg=strength))
    return out


def best_brand_match(query, candidates):
    """Exact first, then difflib. Returns (name, score) or (None, 0.0) below the floor."""
    q = normalise_brand(query)
    if not q or not candidates:
        return None, 0.0
    if q in candidates:
        return q, 1.0
    best, best_score = None, 0.0
    for c in candidates:
        score = difflib.SequenceMatcher(None, q, c).ratio()
        if score > best_score:
            best, best_score = c, score
    if best_score < _MATCH_FLOOR:
        return None, best_score
    return best, best_score


def molecules_equal(a, b):
    if a.name.strip().lower() != b.name.strip().lower():
        return False
    if a.strengthMg is None or b.strengthMg is None:
        return a.strengthMg == b.strengthMg
    return abs(float(a.strengthMg) - float(b.strengthMg)) < 0.001
```

```python
from dataclasses import dataclass, field
from typing import List, Optional

from api.drugs import molecules_equal
from api.models import Molecule

MESSAGES = {
    "exact_match": "This matches your prescription.",
    "strength_mismatch": "Same medicine, different strength. Check with your chemist.",
    "combination_extra": "This strip has extra medicines in it. Check with your chemist.",
    "brand_unreadable": "We could not read the brand, but the medicine matches. Check with your chemist.",
    "missing_from_box": "This medicine is not in the box. Do not skip it - ask your doctor.",
    "not_prescribed": "This is not on your prescription. Do not take it - ask your doctor.",
    "duplicate_molecule": "Two of your medicines contain the same drug. Do not take both - ask your doctor.",
}


@dataclass
class Strip:
    brandText: Optional[str]
    molecules: List[Molecule] = field(default_factory=list)


def _item(verdict, reason, line_id, strip):
    return {
        "verdict": verdict,
        "reason": reason,
        "message": MESSAGES[reason],
        "prescribedLineId": line_id,
        "stripBrandText": strip.brandText if strip else None,
        "stripMolecules": [{"name": m.name, "strengthMg": m.strengthMg}
                           for m in (strip.molecules if strip else [])],
    }


def check_box(medicines, strips):
    items = []
    used = set()

    for med in medicines:
        matched_index = None
        fallback = None
        for i, strip in enumerate(strips):
            if i in used:
                continue
            hits = [m for m in med.molecules
                    if any(molecules_equal(m, s) for s in strip.molecules)]
            if hits and len(hits) == len(med.molecules):
                if len(strip.molecules) > len(med.molecules):
                    fallback = fallback or (i, "combination_extra")
                elif not strip.brandText:
                    fallback = fallback or (i, "brand_unreadable")
                else:
                    matched_index = i
                    break
            elif any(m.name.lower() == s.name.lower() for m in med.molecules
                     for s in strip.molecules):
                fallback = fallback or (i, "strength_mismatch")

        if matched_index is not None:
            used.add(matched_index)
            items.append(_item("matched", "exact_match", med.lineId, strips[matched_index]))
        elif fallback is not None:
            i, reason = fallback
            used.add(i)
            items.append(_item("check", reason, med.lineId, strips[i]))
        else:
            items.append(_item("do_not_take", "missing_from_box", med.lineId, None))

    for i, strip in enumerate(strips):
        if i not in used:
            items.append(_item("do_not_take", "not_prescribed", None, strip))

    seen = {}
    for med in medicines:
        for mol in med.molecules:
            key = mol.name.strip().lower()
            if key in seen and seen[key] != med.lineId:
                items.append(_item("do_not_take", "duplicate_molecule", med.lineId, None))
            else:
                seen[key] = med.lineId
    return items
```

```python
import json
import os

ROUTES = {}


def route(method, path):
    def deco(fn):
        ROUTES[(method.upper(), path)] = fn
        return fn
    return deco


def _match(method, path):
    if (method, path) in ROUTES:
        return ROUTES[(method, path)], {}
    parts = path.strip("/").split("/")
    for (m, pattern), fn in ROUTES.items():
        if m != method:
            continue
        pparts = pattern.strip("/").split("/")
        if len(pparts) != len(parts):
            continue
        params = {}
        for want, got in zip(pparts, parts):
            if want.startswith("{") and want.endswith("}"):
                params[want[1:-1]] = got
            elif want != got:
                break
        else:
            return fn, params
    return None, {}


def respond(status, body):
    return {
        "statusCode": status,
        "headers": {"content-type": "application/json",
                    "access-control-allow-origin": "*",
                    "access-control-allow-headers": "content-type,authorization",
                    "access-control-allow-methods": "GET,POST,PATCH,OPTIONS"},
        "body": json.dumps(body),
    }


@route("GET", "/health")
def health(event, params):
    return respond(200, {"ok": True, "commit": os.environ.get("GIT_SHA", "dev")})


def lambda_handler(event, context):
    ctx = event.get("requestContext", {}).get("http", {})
    method = ctx.get("method", "GET").upper()
    path = ctx.get("path", "/")
    if method == "OPTIONS":
        return respond(204, {})
    fn, params = _match(method, path)
    if fn is None:
        return respond(404, {"code": "not_found", "message": "no route"})
    try:
        return fn(event, params)
    except PermissionError as exc:
        return respond(403, {"code": "forbidden", "message": str(exc)})
    except ValueError as exc:
        return respond(422, {"code": "validation_failed", "message": str(exc)})
```

```python
"""Load the Kaggle A-Z India medicine CSV into the aftercare-drugs table.

Usage: python data/etl_drugs.py data/drugs_raw/medicine_dataset.csv
"""
import csv
import sys

import boto3

from api.drugs import bucket_key, normalise_brand, parse_composition

TABLE = "aftercare-drugs"


def rows(path):
    with open(path, newline="", encoding="utf-8", errors="replace") as fh:
        for row in csv.DictReader(fh):
            name = row.get("name") or ""
            norm = normalise_brand(name)
            if not norm:
                continue
            comp = " + ".join(x for x in (row.get("short_composition1"),
                                          row.get("short_composition2")) if x)
            molecules = parse_composition(comp)
            if not molecules:
                continue
            yield {
                "PK": bucket_key(norm), "SK": norm, "brand": name.strip(),
                "manufacturer": (row.get("manufacturer_name") or "").strip(),
                "packSize": (row.get("pack_size_label") or "").strip(),
                "discontinued": str(row.get("Is_discontinued", "")).lower() == "true",
                "molecules": [{"name": m.name,
                               "strengthMg": str(m.strengthMg) if m.strengthMg else None}
                              for m in molecules],
            }


def main(path):
    table = boto3.resource("dynamodb", region_name="ap-south-1").Table(TABLE)
    seen, written = set(), 0
    with table.batch_writer(overwrite_by_pkeys=["PK", "SK"]) as batch:
        for item in rows(path):
            key = (item["PK"], item["SK"])
            if key in seen:
                continue
            seen.add(key)
            batch.put_item(Item=item)
            written += 1
            if written % 10000 == 0:
                print("written", written, flush=True)
    print("done", written)


if __name__ == "__main__":
    main(sys.argv[1])
```

```python
import boto3

from api.common import DRUGS_TABLE, REGION
from api.drugs import best_brand_match, bucket_key, normalise_brand
from api.models import Molecule

_table = None


def _t():
    global _table
    if _table is None:
        _table = boto3.resource("dynamodb", region_name=REGION).Table(DRUGS_TABLE)
    return _table


def lookup_brand(brand_text):
    """Brand text -> molecules. Unknown brands return [] rather than raising."""
    norm = normalise_brand(brand_text)
    if not norm:
        return []
    try:
        res = _t().query(
            KeyConditionExpression="PK = :p",
            ExpressionAttributeValues={":p": bucket_key(norm)},
            Limit=300)
    except Exception:
        return []
    items = {i["SK"]: i for i in res.get("Items", [])}
    name, _score = best_brand_match(norm, list(items))
    if not name:
        return []
    out = []
    for m in items[name].get("molecules", []):
        strength = m.get("strengthMg")
        out.append(Molecule(name=m["name"],
                            strengthMg=float(strength) if strength else None))
    return out
```

- [ ] **Step 1: Write `api/extract.py`**

```python
import json
import os

import boto3

from api.common import BUCKET, REGION, new_id
from api.frequency import parse_frequency
from api.models import Medicine, Molecule, Plan, RedFlags
from api.validate import GENERIC_RED_FLAG_TEXT

_textract = boto3.client("textract", region_name=REGION)
_bedrock = boto3.client("bedrock-runtime", region_name=REGION)
_s3 = boto3.client("s3", region_name=REGION)

MIN_WORDS_FOR_TEXTRACT = 20
CONFIDENCE_FLOOR = 0.85

PROMPT = """You are reading an Indian hospital discharge summary or OPD prescription.

Below is the exact word list extracted from the page, each with an id.
Return ONLY JSON matching this schema:

{"medicines":[{"lineId":"m1","rawText":"","brand":null,"molecules":[{"name":"","strengthMg":null}],
"form":null,"frequency":null,"foodRelation":"before|after|unspecified","durationDays":null,
"prn":false,"prnCondition":null,"confidence":0.0,"sourceBlockIds":[]}],
"redFlags":{"present":false,"text":"","sourceBlockIds":[]},
"followUp":{"date":null,"with":null,"confidence":0.0},
"patientName":null}

HARD RULES:
- Copy values from the page. NEVER infer, complete or correct a missing value.
- If a strength, frequency or duration is not written on the page, use null.
- frequency must be copied verbatim as written (OD, BD, TDS, HS, SOS, 1-0-1, ...).
- Do NOT convert frequency into times of day. That is done elsewhere.
- sourceBlockIds must list the word ids you read each medicine from. Never invent ids.
- redFlags.present is true ONLY if the page contains an explicit warning-signs or
  "report immediately" section. Copy it verbatim. Never write your own.
- confidence is your own 0-1 reading confidence for that line.

WORDS:
"""


def textract_words(s3_key):
    res = _textract.analyze_document(
        Document={"S3Object": {"Bucket": BUCKET, "Name": s3_key}},
        FeatureTypes=["TABLES", "LAYOUT"])
    words = []
    for block in res.get("Blocks", []):
        if block.get("BlockType") == "WORD":
            words.append({"id": block["Id"][:8], "text": block.get("Text", ""),
                          "box": block["Geometry"]["BoundingBox"]})
    return words


def crop_for(block_ids, words):
    boxes = [w["box"] for w in words if w["id"] in set(block_ids)]
    if not boxes:
        return None
    left = min(b["Left"] for b in boxes)
    top = min(b["Top"] for b in boxes)
    right = max(b["Left"] + b["Width"] for b in boxes)
    bottom = max(b["Top"] + b["Height"] for b in boxes)
    pad = 0.01
    return {"x": max(0.0, left - pad), "y": max(0.0, top - pad),
            "w": min(1.0, right - left + 2 * pad), "h": min(1.0, bottom - top + 2 * pad)}


def _call_model(image_bytes, words, model_id):
    word_list = "\n".join("%s: %s" % (w["id"], w["text"]) for w in words)
    content = [{"text": PROMPT + word_list}]
    if image_bytes:
        content.insert(0, {"image": {"format": "jpeg", "source": {"bytes": image_bytes}}})
    res = _bedrock.converse(
        modelId=model_id or os.environ["BEDROCK_MODEL_ID"],
        messages=[{"role": "user", "content": content}],
        inferenceConfig={"maxTokens": 4000, "temperature": 0})
    text = res["output"]["message"]["content"][0]["text"]
    start, end = text.find("{"), text.rfind("}")
    if start < 0 or end < 0:
        raise ValueError("model returned no JSON")
    return json.loads(text[start:end + 1])


def extract_plan(s3_keys, circle_id, model_id=None):
    all_words, medicines, red_flags, follow_up, patient = [], [], None, None, None

    for key in s3_keys:
        words = textract_words(key)
        source = "textract" if len(words) >= MIN_WORDS_FOR_TEXTRACT else "vision_only"
        image = _s3.get_object(Bucket=BUCKET, Key=key)["Body"].read()
        raw = _call_model(image, words, model_id)
        all_words.extend(words)
        patient = patient or raw.get("patientName")

        for m in raw.get("medicines", []):
            slots, prn = parse_frequency(m.get("frequency") or "")
            mols = [Molecule(name=x.get("name", "").strip().lower(),
                             strengthMg=x.get("strengthMg"))
                    for x in m.get("molecules", []) if x.get("name")]
            block_ids = [b for b in m.get("sourceBlockIds", [])
                         if any(w["id"] == b for w in words)]
            confidence = float(m.get("confidence", 0.0))
            missing = (not mols) or m.get("frequency") is None
            medicines.append(Medicine(
                lineId="m%d" % (len(medicines) + 1), rawText=m.get("rawText", ""),
                brand=m.get("brand"), molecules=mols, form=m.get("form"),
                frequency=m.get("frequency"), slots=slots,
                foodRelation=m.get("foodRelation", "unspecified"),
                durationDays=m.get("durationDays"), prn=bool(m.get("prn") or prn),
                prnCondition=m.get("prnCondition"), confidence=confidence,
                sourceBlockIds=block_ids, source=source,
                needsConfirmation=(confidence < CONFIDENCE_FLOOR or missing
                                   or source == "vision_only" or not block_ids)))

        rf = raw.get("redFlags") or {}
        if rf.get("present") and rf.get("text") and red_flags is None:
            ids = [b for b in rf.get("sourceBlockIds", [])
                   if any(w["id"] == b for w in words)]
            if ids:
                red_flags = RedFlags(source="document", text=rf["text"], sourceBlockIds=ids)
        follow_up = follow_up or raw.get("followUp")

    if red_flags is None:
        red_flags = RedFlags(source="generic", text=GENERIC_RED_FLAG_TEXT, sourceBlockIds=[])

    for med in medicines:
        med.__dict__["crop"] = crop_for(med.sourceBlockIds, all_words)

    return Plan(planId=new_id("pl"), circleId=circle_id, medicines=medicines,
                redFlags=red_flags, patientName=patient, followUp=follow_up)
```

```python
"""Extraction accuracy gate. Needs AWS credentials and uploaded photos.

Run: python -m pytest tests/test_golden.py -m golden -v -s
"""
import glob
import json
import os

import pytest

pytestmark = pytest.mark.golden

FIELDS = ["name", "strength", "slots", "food", "duration"]
GATES = {"name": 0.90, "strength": 0.90, "slots": 0.80, "food": 0.80, "duration": 0.80}


def _score_case(expected, plan):
    got = {m.brand and m.brand.lower(): m for m in plan.medicines}
    hits = {f: 0 for f in FIELDS}
    total = len(expected["medicines"])
    for exp in expected["medicines"]:
        cand = got.get((exp["brand"] or "").lower())
        if cand is None:
            for m in plan.medicines:
                if m.molecules and exp["molecules"] and \
                        m.molecules[0].name == exp["molecules"][0]["name"]:
                    cand = m
                    break
        if cand is None:
            continue
        if cand.molecules and exp["molecules"] and \
                cand.molecules[0].name == exp["molecules"][0]["name"]:
            hits["name"] += 1
        if cand.molecules and exp["molecules"] and \
                cand.molecules[0].strengthMg == exp["molecules"][0]["strengthMg"]:
            hits["strength"] += 1
        if sorted(cand.slots) == sorted(exp["slots"]):
            hits["slots"] += 1
        if cand.foodRelation == exp["foodRelation"]:
            hits["food"] += 1
        if cand.durationDays == exp["durationDays"]:
            hits["duration"] += 1
    return hits, total


def test_extraction_meets_the_gate():
    from api.extract import extract_plan
    prefix = os.environ["GOLDEN_S3_PREFIX"]  # e.g. circles/ci_demo/golden
    totals = {f: 0 for f in FIELDS}
    counts = 0
    for path in sorted(glob.glob("data/golden/*.json")):
        expected = json.load(open(path, encoding="utf-8"))
        plan = extract_plan(["%s/%s.jpg" % (prefix, expected["caseId"])], "ci_test")
        hits, total = _score_case(expected, plan)
        counts += total
        for f in FIELDS:
            totals[f] += hits[f]
        print(expected["caseId"], {f: "%d/%d" % (hits[f], total) for f in FIELDS})
    failures = []
    for f in FIELDS:
        acc = totals[f] / counts if counts else 0.0
        print("ACCURACY %-9s %.2f (gate %.2f)" % (f, acc, GATES[f]))
        if acc < GATES[f]:
            failures.append("%s %.2f < %.2f" % (f, acc, GATES[f]))
    assert not failures, failures
```

```python
import json

import boto3

from api.common import BUCKET, REGION, TABLE, new_id, now_ist
from api.extract import extract_plan
from api.handler import respond, route

_s3 = boto3.client("s3", region_name=REGION)
_ddb = boto3.resource("dynamodb", region_name=REGION)

ALLOWED_TYPES = ("image/jpeg", "image/png", "application/pdf")


@route("POST", "/documents")
def create_document(event, params):
    body = json.loads(event.get("body") or "{}")
    circle_id = body.get("circleId")
    pages = int(body.get("pageCount", 1))
    content_type = body.get("contentType", "image/jpeg")
    if not circle_id or not 1 <= pages <= 10 or content_type not in ALLOWED_TYPES:
        raise ValueError("circleId, pageCount 1-10 and a supported contentType are required")

    document_id = new_id("doc")
    uploads = []
    ext = {"image/jpeg": "jpg", "image/png": "png", "application/pdf": "pdf"}[content_type]
    for page in range(1, pages + 1):
        key = "circles/%s/%s/p%d.%s" % (circle_id, document_id, page, ext)
        uploads.append({"page": page, "key": key, "uploadUrl": _s3.generate_presigned_url(
            "put_object",
            Params={"Bucket": BUCKET, "Key": key, "ContentType": content_type},
            ExpiresIn=900)})

    _ddb.Table(TABLE).put_item(Item={
        "PK": "CIRCLE#%s" % circle_id, "SK": "DOC#%s" % document_id,
        "documentId": document_id, "keys": [u["key"] for u in uploads],
        "createdAt": now_ist().isoformat()})
    return respond(201, {"documentId": document_id, "uploads": uploads})


@route("POST", "/documents/{documentId}/extract")
def extract(event, params):
    body = json.loads(event.get("body") or "{}")
    circle_id = body.get("circleId")
    doc = _ddb.Table(TABLE).get_item(
        Key={"PK": "CIRCLE#%s" % circle_id, "SK": "DOC#%s" % params["documentId"]}
    ).get("Item")
    if not doc:
        return respond(404, {"code": "not_found", "message": "document not found"})

    plan = extract_plan(doc["keys"], circle_id)
    item = plan.to_dict()
    item.update({"PK": "CIRCLE#%s" % circle_id, "SK": "PLAN#%s" % plan.planId,
                 "sourceDocumentIds": [params["documentId"]]})
    _ddb.Table(TABLE).put_item(Item=json.loads(json.dumps(item), parse_float=str))
    return respond(200, plan.to_dict())
```

```python
from datetime import timedelta

from api.models import SLOTS, Dose

DEFAULT_DAYS = 7


def build_doses(plan, start_date, days=7):
    doses = []
    for offset in range(days):
        day = start_date + timedelta(days=offset)
        by_slot = {}
        for med in plan.medicines:
            if med.prn or not med.slots:
                continue
            limit = med.durationDays if med.durationDays is not None else DEFAULT_DAYS
            if offset >= limit:
                continue
            for slot in med.slots:
                by_slot.setdefault(slot, []).append(med.lineId)
        for slot in SLOTS:
            if slot in by_slot:
                doses.append(Dose(
                    doseId="%s#%s#%s" % (plan.circleId, day.isoformat(), slot),
                    date=day.isoformat(), slot=slot,
                    medicineLineIds=sorted(by_slot[slot])))
    return doses
```

```python
import boto3
```

```python
def decide(event, dose_status):
    """Pure decision: (action, needs_followup_schedule)."""
    phase = event.get("phase")
    if dose_status == "given":
        return "none", False
    if phase == "remind":
        return "remind", True
    if phase == "check":
        return "escalate", False
    return "none", False


def _dose(circle_id, dose_id):
    _, date, slot = dose_id.split("#")
    return _ddb.Table(TABLE).get_item(
        Key={"PK": "CIRCLE#%s" % circle_id, "SK": "DOSE#%s#%s" % (date, slot)}).get("Item")


def lambda_handler(event, context):
    circle_id, dose_id = event["circleId"], event["doseId"]
    dose = _dose(circle_id, dose_id) or {}
    action, follow_up = decide(event, dose.get("status", "pending"))

    if action == "remind":
        send_reminder(circle_id, dose)
    elif action == "escalate":
        _ddb.Table(TABLE).update_item(
            Key={"PK": "CIRCLE#%s" % circle_id,
                 "SK": "DOSE#%s#%s" % (dose["date"], dose["slot"])},
            UpdateExpression="SET #s = :missed",
            ConditionExpression="#s = :pending",
            ExpressionAttributeNames={"#s": "status"},
            ExpressionAttributeValues={":missed": "missed", ":pending": "pending"})
        send_escalation(circle_id, dose)

    if follow_up:
        circle = _ddb.Table(TABLE).get_item(
            Key={"PK": "CIRCLE#%s" % circle_id, "SK": "META"}).get("Item") or {}
        minutes = int(circle.get("escalationMinutes", 60))
        at = (datetime.now(IST) + timedelta(minutes=minutes)).astimezone(IST)
        _scheduler.create_schedule(
            Name="check-%s" % dose_id.replace("#", "-"), GroupName="aftercare",
            ScheduleExpression=at.strftime("at(%Y-%m-%dT%H:%M:%S)"),
            ScheduleExpressionTimezone="Asia/Kolkata",
            FlexibleTimeWindow={"Mode": "OFF"}, ActionAfterCompletion="DELETE",
            Target={"Arn": os.environ["REMINDER_SELF_ARN"],
                    "RoleArn": os.environ["SCHEDULER_ROLE_ARN"],
                    "Input": json.dumps({**event, "phase": "check"})})
```

```python
import json
import logging

import boto3

from api.common import REGION, TABLE, redact

log = logging.getLogger()
_ddb = boto3.resource("dynamodb", region_name=REGION)
_ses = boto3.client("ses", region_name=REGION)

SENDER = "aftercare@example.invalid"  # replace with the verified SES identity


def channels_for(member):
    out = []
    if member.get("pushSubscription"):
        out.append("push")
    if member.get("role") == "owner":
        if member.get("whatsappNumber"):
            out.append("whatsapp")
        if member.get("email"):
            out.append("email")
    return out


def _members(circle_id):
    res = _ddb.Table(TABLE).query(
        KeyConditionExpression="PK = :p AND begins_with(SK, :s)",
        ExpressionAttributeValues={":p": "CIRCLE#%s" % circle_id, ":s": "MEMBER#"})
    return res.get("Items", [])


def _push(member, title, body):
    from pywebpush import webpush
    private_key = _ssm.get_parameter(Name="/aftercare/vapid/private",
                                     WithDecryption=True)["Parameter"]["Value"]
    webpush(subscription_info=json.loads(json.dumps(member["pushSubscription"], default=str)),
            data=json.dumps({"title": title, "body": body}),
            vapid_private_key=private_key,
            vapid_claims={"sub": "mailto:%s" % SENDER})


def _email(member, subject, body):
    _ses.send_email(Source=SENDER,
                    Destination={"ToAddresses": [member["email"]]},
                    Message={"Subject": {"Data": subject},
                             "Body": {"Text": {"Data": body}}})


def _whatsapp(member, body):
    _social.send_whatsapp_message(
        originationPhoneNumberId=_ssm.get_parameter(
            Name="/aftercare/whatsapp/phone_id")["Parameter"]["Value"],
        metaApiVersion="v20.0",
        message=json.dumps({"messaging_product": "whatsapp",
                            "to": member["whatsappNumber"],
                            "type": "text", "text": {"body": body}}).encode("utf-8"))


def _fan_out(circle_id, title, body, roles):
    for member in _members(circle_id):
        if member.get("role") not in roles:
            continue
        for channel in channels_for(member):
            try:
                if channel == "push":
                    _push(member, title, body)
                elif channel == "whatsapp":
                    _whatsapp(member, body)
                elif channel == "email":
                    _email(member, title, body)
                break  # first channel that works wins
            except Exception as exc:  # delivery never blocks the dose flow
                log.warning("notify failed channel=%s member=%s err=%s",
                            channel, redact(member.get("SK")), type(exc).__name__)
```

```python
import hashlib
import json

import boto3

from api.common import BUCKET, REGION, TABLE
from api.handler import respond, route

_translate = boto3.client("translate", region_name=REGION)
_polly = boto3.client("polly", region_name=REGION)
_s3 = boto3.client("s3", region_name=REGION)
_ddb = boto3.resource("dynamodb", region_name=REGION)

VOICE = {"hi": "Kajal", "en": "Kajal"}  # Polly has no Kannada voice
SLOT_WORDS = {"morning": "morning", "noon": "afternoon",
              "night": "night", "bedtime": "bedtime"}


def translate_text(text, lang):
    if not text or lang == "en":
        return text
    return _translate.translate_text(Text=text, SourceLanguageCode="en",
                                     TargetLanguageCode=lang)["TranslatedText"]


def spoken_schedule(plan):
    lines = []
    for slot, word in SLOT_WORDS.items():
        meds = [m for m in plan.medicines if slot in m.slots]
        if not meds:
            continue
        names = ", ".join(m.brand or (m.molecules[0].name if m.molecules else "") for m in meds)
        food = {"before": "before food", "after": "after food"}.get(
            meds[0].foodRelation, "")
        lines.append("In the %s: %s. %s." % (word, names, food))
    return " ".join(lines)


@route("GET", "/plans/{planId}/audio")
def audio(event, params):
    q = event.get("queryStringParameters") or {}
    lang = q.get("lang", "hi")
    circle_id = q.get("circleId")
    item = _ddb.Table(TABLE).get_item(
        Key={"PK": "CIRCLE#%s" % circle_id, "SK": "PLAN#%s" % params["planId"]}).get("Item")
    if not item:
        return respond(404, {"code": "not_found", "message": "plan not found"})

    from api.models import Plan
    plan = Plan.from_dict(json.loads(json.dumps(item, default=str)))
    text = spoken_schedule(plan)
    # Polly has no Kannada voice: Kannada users hear Hindi audio (spec section 4).
    speak_lang = "hi" if lang in ("hi", "kn") else "en"
    spoken = translate_text(text, "hi") if speak_lang == "hi" else text

    key = "audio/%s-%s.mp3" % (params["planId"],
                               hashlib.sha256(spoken.encode()).hexdigest()[:10])
    try:
        _s3.head_object(Bucket=BUCKET, Key=key)
    except Exception:
        mp3 = _polly.synthesize_speech(Text=spoken, OutputFormat="mp3",
                                       VoiceId=VOICE[speak_lang], Engine="neural")
        _s3.put_object(Bucket=BUCKET, Key=key, Body=mp3["AudioStream"].read(),
                       ContentType="audio/mpeg")
    url = _s3.generate_presigned_url("get_object",
                                     Params={"Bucket": BUCKET, "Key": key}, ExpiresIn=3600)
    return respond(200, {"url": url, "spokenLanguage": speak_lang, "text": spoken})
```

```python
import json
import os
import time
import urllib.request

import boto3
import jwt

from api.common import REGION

_ssm = boto3.client("ssm", region_name=REGION)
_jwks = None
_secret_cache = None


def _secret():
    global _secret_cache
    if _secret_cache is None:
        _secret_cache = _ssm.get_parameter(Name="/aftercare/circle_token_secret",
                                           WithDecryption=True)["Parameter"]["Value"]
    return _secret_cache


def issue_circle_token(circle_id, role, ttl_seconds=90 * 24 * 3600):
    payload = {"circleId": circle_id, "role": role,
               "exp": int(time.time()) + ttl_seconds, "iss": "aftercare"}
    return jwt.encode(payload, _secret(), algorithm="HS256")


def verify_circle_token(token):
    try:
        return jwt.decode(token, _secret(), algorithms=["HS256"], issuer="aftercare")
    except Exception as exc:
        raise PermissionError("invalid circle token: %s" % type(exc).__name__)


def _cognito_claims(token):
    global _jwks
    pool_id = os.environ["USER_POOL_ID"]
    if _jwks is None:
        url = ("https://cognito-idp.%s.amazonaws.com/%s/.well-known/jwks.json"
               % (REGION, pool_id))
        _jwks = json.loads(urllib.request.urlopen(url, timeout=5).read())
    header = jwt.get_unverified_header(token)
    key = next((k for k in _jwks["keys"] if k["kid"] == header["kid"]), None)
    if key is None:
        raise PermissionError("unknown key id")
    public_key = jwt.algorithms.RSAAlgorithm.from_jwk(json.dumps(key))
    return jwt.decode(token, public_key, algorithms=["RS256"],
                      audience=os.environ["USER_POOL_CLIENT_ID"])


def principal_from_event(event):
    header = (event.get("headers") or {}).get("authorization", "")
    token = header[7:] if header.lower().startswith("bearer ") else ""
    if not token:
        raise PermissionError("missing token")
    try:
        claims = _cognito_claims(token)
        return {"sub": claims["sub"], "circleId": None, "role": "owner"}
    except PermissionError:
        raise
    except Exception:
        claims = verify_circle_token(token)
        return {"sub": "caregiver", "circleId": claims["circleId"], "role": claims["role"]}


def require(principal, circle_id, roles=("owner", "caregiver")):
    if principal.get("role") not in roles:
        raise PermissionError("role %s not permitted" % principal.get("role"))
    if principal.get("circleId") and principal["circleId"] != circle_id:
        raise PermissionError("token is not for this circle")
    return principal
```

```python
import json
import os
import secrets
import time

import boto3

from api.auth import issue_circle_token, principal_from_event, require
from api.common import REGION, TABLE, new_id
from api.handler import respond, route

_ddb = boto3.resource("dynamodb", region_name=REGION)
WEB_ORIGIN = os.environ.get("WEB_ORIGIN", "https://main.example.amplifyapp.com")


@route("POST", "/circles")
def create_circle(event, params):
    principal = principal_from_event(event)
    body = json.loads(event.get("body") or "{}")
    circle_id = new_id("ci")
    table = _ddb.Table(TABLE)
    table.put_item(Item={"PK": "CIRCLE#%s" % circle_id, "SK": "META",
                         "circleId": circle_id, "name": body.get("name", "Family"),
                         "language": body.get("language", "kn"),
                         "escalationMinutes": 60})
    table.put_item(Item={"PK": "CIRCLE#%s" % circle_id,
                         "SK": "MEMBER#%s" % principal["sub"],
                         "role": "owner", "email": body.get("email")})
    return respond(201, {"circleId": circle_id})


@route("POST", "/circles/{circleId}/invite")
def invite(event, params):
    principal = require(principal_from_event(event), params["circleId"], roles=("owner",))
    token = secrets.token_urlsafe(16)
    expires = int(time.time()) + 24 * 3600
    _ddb.Table(TABLE).put_item(Item={"PK": "INVITE#%s" % token, "SK": "META",
                                     "circleId": params["circleId"], "role": "caregiver",
                                     "expiresAt": expires, "used": False})
    url = "%s/join?c=%s&t=%s" % (WEB_ORIGIN, params["circleId"], token)
    return respond(201, {"token": token, "url": url,
                         "expiresAt": expires, "qrPayload": url})


@route("POST", "/circles/{circleId}/join")
def join(event, params):
    body = json.loads(event.get("body") or "{}")
    table = _ddb.Table(TABLE)
    item = table.get_item(Key={"PK": "INVITE#%s" % body.get("token", ""),
                               "SK": "META"}).get("Item")
    if not item or item.get("used") or item["circleId"] != params["circleId"]:
        return respond(404, {"code": "not_found", "message": "invite not valid"})
    table.update_item(Key={"PK": "INVITE#%s" % body["token"], "SK": "META"},
                      UpdateExpression="SET used = :t",
                      ExpressionAttributeValues={":t": True})
    table.put_item(Item={"PK": "CIRCLE#%s" % params["circleId"],
                         "SK": "MEMBER#caregiver", "role": "caregiver"})
    return respond(200, {"sessionToken": issue_circle_token(params["circleId"], "caregiver"),
                         "role": "caregiver", "circleId": params["circleId"]})
```
